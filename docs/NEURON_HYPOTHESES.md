# 시분할 TI 가설 3종 — 문헌 검증과 NEURON 실험 설계

> 사용자 제안(2026-08): ①시분할의 생리적 가능성 ②off-target 회복 효과 ③고주파+짧은 버스트 시너지
> 각 가설이 잘 정의됐는지, 문헌이 뭐라 하는지, NEURON 으로 어떻게 판정할지를 정리한다.

---

## 0. 왜 이 셋은 NEURON 이 필요한가 — 기존 음성결과와의 관계

프로젝트는 이미 **"시분할은 강도 이득 불가"** 를 확립했다([[seqti-fair-reversal]]).
근거는 **볼록결합 상한**이다: 시간평균 엔벨로프는 성분 몽타주들의 볼록결합이므로
어떤 조합도 최대 성분을 넘지 못한다.

**이 논증은 필드 수준에서 수학적으로 옳지만, 뉴런에는 그대로 전이되지 않는다.**

> 볼록결합 상한은 **"뉴런이 시간평균 필드에 반응한다"**를 암묵적으로 가정한다.
> 실제 뉴런은 (a) 역치가 있고 (b) 기억(Na 불활성화·느린 K)이 있고 (c) 블록이 있다.
> 셋 다 비선형이라 시간평균으로 환원되지 않는다.

**즉 세 가설은 기존 음성결과에 의해 반박되지 않는다.** 필드가 답할 수 없는 층에 있다.
이게 NEURON 을 쓸 정당한 이유이고, 동시에 **결과가 음성이면 그건 새로운 음성결과**다
(필드 수준이 아니라 생리 수준에서 닫히는 것).

---

## 1. 가설 H1 — 시분할 자극이 연속 TI 와 같은 효과를 낼 수 있는가

### 제기된 문제
짧게 스위칭하면 **연속적인 엔벨로프를 형성하기 어렵고**, 자극 입력 위치가 바뀌는 전이 효과도 있다.

### 평가: 잘 정의된 질문이다. 핵심은 **세 시간척도의 대소관계**다.

| 시간척도 | 값 (현재 설정) | 의미 |
|---|---|---|
| 스위칭 주기 `T_sw` | **실험 변수** | 몽타주 교체 간격 |
| 포락선 주기 `1/Δf` | **10 ms** (Δf=100 Hz) | 뉴런이 복조해야 할 신호 |
| 막 시상수 `τ_m` | ~0.03~0.1 ms (MRG 결절) | 반송파 저역통과 |
| 블록 형성 시간 | **~100 ms 이상** (문헌 §4) | 탈분극 블록 |

세 구간이 정성적으로 다르다:

- **`T_sw ≪ 1/Δf`** (예: 0.1 ms) → 뉴런이 몽타주들의 **평균**을 본다.
  여기서는 볼록결합 상한이 실제로 적용된다 → **이득 없음 예상**.
- **`T_sw ≈ 1/Δf`** (예: 10 ms) → **엔벨로프가 매번 잘린다.** 가장 위험한 구간.
  포락선 한 주기를 다 못 채우면 복조 자체가 약해진다.
- **`T_sw ≫ 1/Δf`** (예: 50~100 ms) → 각 슬롯이 사실상 **독립적인 연속 TI**.
  엔벨로프 손실 없음. 여기가 sweet spot 후보다.

> **예측**: 이득이 있다면 `T_sw` 가 **포락선 주기보다 충분히 크고 블록 형성시간보다 작은** 구간,
> 즉 대략 **20~100 ms** 에서 나온다. 사용자가 말한 "짧게짧게"보다는 **긴 쪽**일 수 있다.

### 실험 E1 — 스위칭 주기 스윕

```
몽타주  : 표적을 공유하는 2개 (A, B) — off 분포가 최대한 다른 쌍을 고를 것
조건    : 연속 A · 연속 B · 시분할(A↔B) with T_sw ∈ {0.5, 2, 5, 10, 20, 50, 100} ms
측정    : 표적 recruitment(g) · off recruitment(g) · 개시위치 · 블록 플래그
대조    : 볼록결합 예측(필드 수준 시간평균)과 비교 — 이걸 넘어야 "생리적 이득"
```

**판정**: 어떤 `T_sw` 에서도 볼록결합 예측을 못 넘으면 → **생리 수준에서도 시분할 이득 없음**(강한 음성결과).
넘는 구간이 있으면 → 그 구간이 sweet spot 이고, 왜 거기인지는 시간척도로 설명된다.

## 2. 가설 H2 — off-target 이 "쉴" 수 있는가 ★가장 가치 있음

### 제기된 문제
자극을 주면 값이 올라가고 멈추면 식듯이 내려온다. 몽타주를 돌리면 off 영역마다 쉬는 시간이 생기므로
**단순히 부하를 나누는 것 이상**일 것이다.

### 평가: 생리적 실체가 있다. 그리고 **필드 논증으로는 원리적으로 답할 수 없다.**

"부하 누적 ↔ 회복"의 실제 기전 후보:

| 기전 | 시상수 | 역할 |
|---|---|---|
| **Na 불활성화 (h)** | 회복 ~수 ms | 반복 자극 시 발화 가능 채널이 줄어듦 |
| **지속성 Na (Nap)** | — | 느린 탈분극 누적 → 역치 접근 |
| **느린 K (Ks)** | 수십 ms | 순응(accommodation) — 발화를 억제하는 방향 |
| **탈분극 블록** | 형성 ~100 ms+ | 완전 차단, 회복은 수 초 |

MRG 결절이 **Naf · Nap · Ks · Lk** 를 다 갖고 있으므로(`axnode` 기전) 이 동역학이 모델에 실재한다.

**핵심 비대칭**: 표적은 **모든 슬롯에서** 자극받지만(공통 표적이므로), 특정 off 영역은 **일부 슬롯에서만**
강하게 자극받는다. 그래서 표적은 연속 누적, off 는 간헐 누적 + 회복.

> 필드 수준에서도 이 비대칭은 보인다(그게 "부하 분산"). **사용자의 주장은 그 이상이라는 것**이고,
> 그 초과분은 **회복 동역학이 비선형이기 때문에** 생긴다 → NEURON 만이 잴 수 있다.

### 실험 E2 — 선형 예측 대비 초과 이득

이게 핵심 설계다. **"1/K 듀티" 선형 예측을 명시적 대조군으로 세운다.**

```
설정    : K개 몽타주(K=2,3,4). 전부 같은 표적, off 분포는 서로 다름
조건 ①  : 연속 단일 몽타주 A (기준)
조건 ②  : 시분할 K개 회전, T_sw = E1 에서 찾은 최적값
조건 ③  : ★선형 대조 — A 를 **듀티 1/K 로 껐다 켰다** (같은 off 영역이 계속 쉬지만
          "다른 위치로 옮기는" 효과는 없음)
측정    : **표적 recruitment 를 맞춘 상태에서** off 발화율
```

**이 세 조건의 비교가 가설을 정확히 가른다:**

| 결과 | 해석 |
|---|---|
| ② ≈ ③ | 이득은 **순전히 듀티(쉬는 시간)** 때문. "위치를 돌린다"는 부가가치 없음 |
| ② < ③ | ★**위치 회전 자체에 이득**이 있다 = 사용자 가설 지지 |
| ② ≈ ① | 회복이 너무 빨라(또는 느려) 시분할이 무의미 |

**추가 관측**: off 섬유에서 **막전위·h·Ks 궤적을 직접 기록**하면 "쉰다"는 게 실제로 무엇인지
보여줄 수 있다. 역치만 보면 기전을 모른다. NEURON 은 상태변수를 그대로 볼 수 있는 게 장점이다.

> **주의 — 반대 방향 가능성**: Ks 순응은 off 를 **덜 발화하게** 만드는 방향이라 사용자에게 유리하지만,
> 회복 중 Na 불활성화가 풀리면 오히려 **다시 잘 발화**하게 된다. 두 효과의 부호가 반대다.
> 어느 쪽이 이기는지는 시간척도에 달렸고, 그게 정확히 이 실험이 재는 것이다.

## 3. 가설 H3 — 고주파 + 짧은 버스트 시너지

### 제기된 주장
> "고주파로 올라갈수록 더 잘 침투하지만 유효한 자극이 오래가지 않고 역치가 높아진다.
> 그러니 고주파를 쓰되 짧게짧게 주면 유효 자극 시간이 길 필요가 없어 시분할의 강점이 커진다."

### 문헌 검증 — 세 부분으로 나눠 보면 **둘은 맞고 하나는 정정 필요**하다

#### ✅ 역치는 주파수와 함께 오른다 — **맞다**

kHz 대역에서 위상 지속시간(phase duration)이 짧아져 이온채널에 전하가 다 전달되기 전에 위상이
바뀌므로 막을 가로지르는 전류가 줄고 **더 큰 전류가 필요**해진다.
(강도-지속시간 관계의 kHz 판)

실측 예: 감마 진동 변조에 필요한 필드가 **100 Hz 반송파 ~5 V/m → 1 kHz ~60 V/m → 2 kHz ~80 V/m**.
2 kHz 에서 두피 전류가 **~220 mA** 필요하다는 계산이 나온다.

> 다만 단조증가는 아니다 — 25 kHz 부근에서 최소를 찍고 88 kHz 까지 39% 다시 오른다는 보고도 있다.
> **1~10 kHz 구간에서는 "오른다"가 맞다.**

#### ⚠️ "고주파가 더 잘 침투한다" — **정정 필요. 우리 모델 안에서는 성립하지 않는다**

문헌이 말하는 침투 이점의 실체는 **피부·전극 계면 임피던스가 주파수에 따라 낮아지는 것**이다
(용량성 계면). 조직 안에서 전기장이 더 깊이 들어가는 게 아니다.

**우리 리드필드는 준정적이라 주파수와 무관하다**(SETUP.md §5-3, `σ ≫ ωε`).
kHz 대역 조직의 표피깊이는 **수 미터** 수준이라 표피효과가 아예 없다.

> **결론: 시뮬레이션 안에서 반송파를 올리면 이득은 0 이고 역치만 오른다.**
> 계면 임피던스 이점은 **모델 밖**(전극-두피 경계)의 실제 전달 문제이고, 우리는 전극에
> 전류·전압을 직접 부과하므로 그 층이 없다.
>
> → H3 의 "침투" 부분은 **NEURON 으로 검증할 수 없다.** 검증하려면 전극 계면 모델이 필요하고
> 그건 이 프로젝트 범위 밖이다. 논문에서 주장할 때도 이 구분을 지켜야 한다.

#### ✅ "유효 자극이 오래 못 간다" — **맞다. 그리고 이게 H3 의 살아있는 핵심이다**

kHz 자극의 **onset response** 와 블록 형성이 문헌에 잘 정리돼 있다:

- **Phase I onset**: ~100 ms, 한 번의 융합 연축
- **Phase II**: 1~30초 이상, 낮지만 지속적인 onset 활동
- **블록 확립 후**는 완전 차단, **회복은 수 초 내로 빠르고 완전**

우리 데이터와도 맞는다 — 2 kHz 에서 이미 **28~41% 가 비단조**(발화→블록→재발화).

> **그래서 H3 의 핵심 논리는 살아남는다**: 블록이 자리잡는 데 ~100 ms 이상 걸리므로,
> **그보다 짧게 스위칭하면 블록을 피할 수 있다.**

#### ⚠️ 단, 정반대 위험이 있다

onset response 는 **블록 전에 활동이 증가하는** 구간이다. 짧은 버스트를 반복하면
**onset 만 반복해서 겪을** 수 있고, 그러면 off-target 활성화가 오히려 **늘어난다.**

> 이건 kHz 블록 임상 응용에서 실제로 문제가 되는 지점이다(onset response 가 임상 전이를 막는 요인).
> **H3 는 "블록 회피"와 "onset 반복" 사이의 줄타기**이고, 어느 쪽이 이기는지가 실험 대상이다.

### 실험 E3 — 주파수 × 버스트 길이

```
반송파  : f ∈ {2, 4, 8} kHz  (Δf=100 Hz 고정)
버스트  : T_sw ∈ {5, 20, 100, 500} ms  — 블록 형성시간(~100 ms)을 걸치도록
측정    : 표적 역치 · off 역치 · 블록 발생률 · **onset 스파이크 수**(★새 관측량)
```

**판정 지표**: 고정된 표적 recruitment 에서의 off 발화율.
`(고주파 + 짧은 버스트)` 가 `(2 kHz + 연속)` 을 이기는 조합이 있는가.

> onset 스파이크를 따로 세는 게 중요하다 — 역치만 보면 onset 반복 위험을 놓친다.

## 4. 실행 순서 제안

| 순서 | 실험 | 이유 |
|---|---|---|
| 1 | **E1 (스위칭 주기)** | H2·H3 가 전부 `T_sw` 를 전제하므로 먼저 최적 구간을 잡아야 한다 |
| 2 | **E2 (선형 대조)** | 가장 가치 있는 가설. ②vs③ 비교가 핵심 |
| 3 | E3 (주파수×버스트) | 주파수 스윕(`MAC_FREQ_SWEEP_HANDOFF.md`)과 통합하면 비용 절감 |

**선결 조건 — 윈도 쪽 준비물**

E1~E3 는 지금 인계 형식으로는 못 돌린다. 필요한 것:

1. **몽타주 K개 세트** — 같은 표적, off 분포는 최대한 다르게.
   `optimize/timemux.py` 의 `optimize_timemux(K_slots=K, max_electrodes=…)` 가 이미 그런 조합을 뽑는다.
2. **각 몽타주의 Ve1/Ve2 를 한 파일에** — `fiberlead.export_candidates` 에 K개를 넘기면 된다.
3. **스위칭 스케줄** — 맥 하네스가 `e_ext(t)` 를 만들 때 슬롯별로 Ve 세트를 갈아끼우도록
   시간축 정의를 넘겨야 한다. 이건 **인계 형식 확장**이 필요하다(현재는 몽타주당 정적 Ve 뿐).

> 3번이 실질적인 작업이다. `export_candidates` 에 `schedule` 항목(슬롯 순서·`T_sw`·듀티)을
> 추가하고 맥 하네스가 그걸 읽게 하면 된다.

## 5. 정직한 사전 평가

| 가설 | 성공 가능성 | 성공/실패 어느 쪽이든 가치 |
|---|---|---|
| H1 | 중간 | sweet spot 구간이 시간척도로 설명되면 그 자체가 결과. 없으면 **생리 수준 음성결과**(필드 수준 음성보다 강함) |
| **H2** | **중간~높음** | ★②vs③ 비교가 깔끔하다. 어느 쪽이든 명확한 답. **"위치 회전에 부가가치가 있는가"는 아직 아무도 안 물은 질문** |
| H3 | 낮음~중간 | "침투" 부분은 모델 밖이라 접어야 함. **"블록 회피 vs onset 반복" 줄타기**만 남는데 onset 쪽이 이길 공산이 있다 |

프로젝트가 지금까지 음성결과를 정직하게 쌓아온 노선([[seqti-fair-reversal]])과 일관되게,
**셋 다 음성이어도 보고할 가치가 있다** — 특히 H2 는 시분할 TI 의 마지막 생리적 희망을
정면으로 닫는 결과가 된다.
