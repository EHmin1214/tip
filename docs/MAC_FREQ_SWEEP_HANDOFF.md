# 맥 NEURON 인계 (2차) — 주파수 스윕

> 1차(`0804_NEURON_result/`)는 **f₁=2000 / f₂=2100 한 점**에서만 돌았다.
> 이번엔 그 축을 훑어 **결론의 적용 범위**와 **TI 기여분**을 확정한다.
>
> **윈도 쪽에서 새로 만들 데이터가 없다.** 리드필드가 준정적이라 Vₑ는 주파수와 무관하므로
> 1차에 넘긴 `data/fibercand_hippoL_full.npz` 의 `Ve1`/`Ve2` 를 **그대로 재사용**한다.
> 바뀌는 건 하네스가 만드는 시간 파형의 f₁·f₂ 뿐이다.

---

## 1. 왜 하는가 — 질문 4개

| # | 질문 | 왜 필요한가 |
|---|---|---|
| **Q4** | **Δf=0 에서도 켜지는가** | ★**필수 통제.** Δf=0 이면 맥놀이가 없어 **포락선 자체가 없다**(SETUP.md §5-3). 그런데도 비슷하게 켜지면 지금까지 본 활성화는 TI 복조가 아니라 **반송파 직접자극**이다. 프로젝트 전체 전제의 검증 |
| **Q5** | **af>field 가 주파수에 걸쳐 유지되는가** | ★1차의 79.2% 는 **2 kHz 한 점** 결과다. 여러 f 에서 유지되면 **기전 수준 결론**, 2 kHz 에서만이면 **특정 조건의 관찰**로 격하. 주장 강도를 정한다 |
| **Q6** | **kHz 블록이 주파수에 따라 어떻게 변하나** | 1차에서 28~41% 비단조 확인. 반송파를 올리면 늘 것으로 예상 — 용량·안전 설계에 직결. 같은 실행에서 공짜로 나온다 |
| **Q7** | 최적 반송파가 있는가 | 탐색적. TI 는 **필드가 주파수 무관**이라 침투·분포는 그대로고 뉴런 응답만 바뀐다 → 트레이드오프가 순수 생리적 |

> Q4·Q5 는 해야 하고, Q6 는 부산물, Q7 은 음성이어도 무방하다.

## 2. 조건 설계

**두 축을 분리한다.** 1차 조건(f₁=2000·Δf=100)이 두 축의 교차점이므로 **재실행 불필요** —
기존 결과를 그 점으로 쓰면 된다.

### 축 A — 반송파 (Δf = 100 Hz 고정)

| f₁ | f₂ | 비고 |
|---:|---:|---|
| 1000 | 1100 | |
| *2000* | *2100* | *1차 결과 재사용 — 실행 안 함* |
| 4000 | 4100 | |
| (8000) | (8100) | 선택 — 비용 큼(§3) |

### 축 B — 맥놀이 (f₁ = 2000 Hz 고정)

| Δf | f₂ | 비고 |
|---:|---:|---|
| **0** | 2000 | ★**Q4 통제** |
| 20 | 2020 | tstop 늘려야 함(§3) |
| *100* | *2100* | *1차 결과 재사용* |
| 500 | 2500 | |

**새로 돌릴 조건 = 5개** (1000·4000 · Δf 0·20·500). 8000 을 넣으면 6개.

## 3. ★실행 파라미터 — 1차와 맞추되 두 가지만 조건별로 바꾼다

1차 설정(`0804_NEURON_result/MAC_RESULTS_HANDOFF.md` §2)을 **그대로** 쓴다:
MRG 10 µm · absorbing 말단 · 모델 21.0 mm/19절 · 이득격자 2→500 20점 · 램프 30 ms ·
`arclen[i]` 중앙정렬 후 보간 · 4프로세스.

바꾸는 것은 **dt 와 tstop** 둘뿐이다.

### (a) dt — 반송파를 해상해야 한다

**주기당 20점 이상**을 권한다: `dt ≤ 1 / (20·f₁)`.

| f₁ | 주기 | 필요 dt |
|---:|---:|---:|
| 1000 | 1.00 ms | ≤ 50 µs |
| 2000 | 0.50 ms | ≤ 25 µs |
| 4000 | 0.25 ms | ≤ 12.5 µs |
| 8000 | 0.125 ms | ≤ 6.25 µs |

1차에서 쓴 dt 를 `d₂ₖ` 라 하면 4 kHz 는 `d₂ₖ/2`, 8 kHz 는 `d₂ₖ/4`. **비용이 그만큼 곱해진다.**

### (b) tstop — 포락선 주기가 창 안에 충분히 들어와야 한다

집계창(t≥45 ms)에 **맥놀이 주기 5개 이상**이 들어가야 한다. 포락선 주기 = `1/Δf`.

| Δf | 포락선 주기 | 필요 창 | **tstop** |
|---:|---:|---:|---:|
| 500 | 2 ms | 10 ms | **110** (1차와 동일) |
| 100 | 10 ms | 50 ms | 110 (1차) |
| 20 | **50 ms** | **250 ms** | **300** ← 2.7배 비쌈 |
| 0 | 없음 | — | **110** (비교 위해 동일 유지) |

> Δf=0 은 포락선이 없으므로 정상상태만 보면 된다. 그래도 1차와 **직접 비교**하려면
> tstop·램프·집계창을 똑같이 두는 게 맞다.

## 4. 섬유·몽타주 부분집합

### 몽타주 — **2종** (`field_opt`, `af_opt`)

`gaf_opt` 는 뺀다. 근거:
- 1차에서 표적 192개 중 **154개(80%) 역치 완전 동률**
- 윈도 쪽 조밀 off(300시드·1200섬유) 재탐색에서 **af 와 gaf 의 최적 몽타주가 전극·비율까지 완전 일치**
  (성긴 off 에서 `O2` vs `O1` 로 갈렸던 건 아티팩트)

즉 **af 와 gaf 는 목적함수로서 구분되지 않는다.** 비용 1/3 절감.
나중에 필요하면 같은 조건으로 gaf 만 추가하면 된다.

> 1차 보고서 §4-① 의 "선택성은 af 8.40 vs gaf 4.88 로 af 가 확실히 낫다"는 **단일 작동점**
> 비교라 격자 양자화(±17%)에 취약하다. 작동점을 맞추거나 ROC AUC 로 보면 gaf 가 오히려
> 낫게 나온다(`analyze_neuron_results.py`). 이번엔 그 함정을 피해 AUC 를 함께 보고할 것.

### 섬유 — **392개** (표적 192 전부 + off 200)

```python
rng = np.random.default_rng(20260804)          # ★이 시드 고정
off_idx = np.where(~target)[0]
sub = np.sort(np.concatenate([np.where(target)[0],
                              rng.choice(off_idx, 200, replace=False)]))
```

표적은 전부 써야 짝지은 비교(Q5)가 1차와 직접 비교된다. off 200 이면 AUC 표준오차가
약 ±0.03 이라 판정에 충분하다. **1차 결과도 같은 `sub` 로 잘라서** 2 kHz 점을 만들 것.

## 5. 비용

1차 실적: 914섬유 × 3몽타주 × 20격자 = 54,840회 / **3.5시간** (4프로세스).
→ 392섬유 × 2몽타주 = **기준 1.0시간/조건** (tstop 110, dt=d₂ₖ 기준).

| 조건 | tstop | dt | 상대비용 | 시간 |
|---|---:|---:|---:|---:|
| f 1000, Δf 100 | 110 | 2·d₂ₖ | 0.5 | **0.5 h** |
| f 4000, Δf 100 | 110 | d₂ₖ/2 | 2.0 | **2.0 h** |
| f 2000, Δf 0 | 110 | d₂ₖ | 1.0 | **1.0 h** |
| f 2000, Δf 20 | 300 | d₂ₖ | 2.7 | **2.7 h** |
| f 2000, Δf 500 | 110 | d₂ₖ | 1.0 | **1.0 h** |
| **소계** | | | | **7.2 h** |
| (선택) f 8000, Δf 100 | 110 | d₂ₖ/4 | 4.0 | +4.0 h |

**하룻밤이면 핵심 5조건이 끝난다.** 시간이 빠듯하면 우선순위는
**Δf=0 → f 4000 → Δf 500 → f 1000 → Δf 20** 순 (Q4 → Q5 → Q6 순서).

## 7. 함정

- **격자 양자화**: 8점/decade(33% 간격)라 역치가 ±17% 로 양자화된다. 주파수 간 차이가
  이보다 작으면 격자에 묻힌다. **조건 간 비교에서 무승부가 많으면 그 섬유만 이분탐색**할 것.
- **저 Δf 에서 창이 짧으면 포락선을 못 본다** — §3(b) 의 tstop 규칙을 지킬 것. Δf=20 을
  tstop 110 으로 돌리면 맥놀이 1.3주기밖에 안 들어가 결과가 무의미해진다.
- **고 f 에서 dt 가 크면 반송파가 앨리어싱된다** — §3(a). 이건 조용히 틀린 답을 준다.
- **말단 조건은 이번에도 absorbing 만.** 1차 §5 의 사유(궤적 자르기 길이가 숨은 자유
  파라미터)가 그대로 유효하다.
- **1차와 비교할 때는 반드시 같은 `sub` 로 자를 것.** 914 전체 vs 392 부분집합을 섞어
  비교하면 안 된다.
