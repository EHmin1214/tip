## 0. 요약

### 0.1 출발점과 도착점

**출발 가설**: 소수 전극을 시간축에서 여러 각도로 순차 스위핑하면(Sequential Multi-Angle TI),
전극 경제성을 유지하면서 다전극 TI(mTI)급 초점을 얻을 수 있다. 대표 표적은 좌측 해마.

**도착점**: 원 가설은 **공정 대조군 앞에서 대부분 닫혔고**, 남은 이득은 처음 생각한 것과
다른 축(방향)에 있다. 그 과정에서 만들어진 **플랫폼·검증 방법론·음성 결과**가 실질 산출물이다.

| 항목 | 판정 |
|---|---|
| 순차 시분할이 **강도**를 올린다 | **기각** — 시간평균은 볼록결합이라 최고 단일 몽타주를 원리적으로 못 넘음 |
| 순차 시분할이 **초점**을 올린다 | **조건부 참** — 방향 잣대에서 ×1.18~1.76, 기전은 Jensen 여유분 하나. 니치는 **표층**(심부 아님) |
| 위상(복소 전류)이 이득을 준다 | **기각** — 실용 강도 영역에서 <2% |
| 반송파 3개 이상(N>2)이 이득을 준다 | **기각** — 최적 N ≤ 2 |
| 배열(다전극 동시)이 심부에 유리하다 | **참** — 시분할·2쌍보다 우세 |
| TI가 심부 **선택성**을 만든다 | **기각** — off 축삭이 먼저 켜짐(필드·NEURON 양쪽 확인) |
| 전기생리를 목적함수에 넣으면 배치가 나아진다 | **확인 안 됨** — 네 갈래 전부 |

## 1. 플랫폼 구축

### 1.1 물리 기반 — 리드필드

**모델**: IT'IS **MIDA** 인체 두부 모델. 격자 185×254×228(10.7 M 셀), 뇌 복셀 **1,907,678개**.
Sim4Life 준정전(QS) 솔버로 전극별 단위전류 응답을 풀어 리드필드로 저장한다.

준정전 근사가 정당한 이유: kHz 대역 조직에서 σ ≫ ωε 이므로 필드 패턴이 **주파수에 무관**하다.
따라서 리드필드 한 벌로 모든 반송파를 다룰 수 있고, **주파수는 뉴런 동역학으로만 들어온다**.
이 사실이 뒤의 4부(생리 검증) 설계를 규정한다.

**전극 풀 확장**: 표준 10-10 배열 60전극으로 시작해, 하부 링 10개(F9/F10·FT9/FT10·T9/T10·
TP9/TP10·P9/P10)를 추가 솔브해 **70전극**으로, 이후 3 cm² 전극 재구축에서 **84전극**으로 늘렸다.
하부 링은 심부 표적에 실제로 쓰인다(뒤 3.4의 최적 몽타주에 T9·T10이 등장).

**★초기에 잡은 치명적 결함 — 좌표 디코딩**

리드필드 행(1,907,678개)을 조밀격자로 `neural // (ny*nz)` 식으로 디코딩하고 있었다. 실제
행↔(i,j,k) 대응은 별도 파일 `bmask1010.npy` 에 있다. 증상은 뇌 중심이
`[−97, 249, 37]`(틀림) vs `[−29, 286, 38]`(맞음, 전극 정중선 −28과 일치)로 나온 것.

**무효화 범위**: 좌표 구(球)로 정의한 표적 전부. "좌시상 구 표적"은 실제 공간에서 반경 92 mm로
흩어진 판이었다. **살아남은 것**: 행-마스크 기반 표적(해마), 물리 검증, 문헌 대조.

이 사건이 이 프로젝트의 검증 규약을 만들었다 — **인덱싱 가정은 반드시 실측으로 확인한다.**

하위폴더를 찾아주므로 파일이 옮겨 다녀도 안 깨진다.

1. **깊이 오산** — `research/validate/x.py` 는 `dirname` 이 3번 필요한데 경로의 `/` 개수(2)로

2. **정의보다 먼저 사용** — 치환이 `sys.path.insert` 를 앞줄에 넣고 `REPO` 정의를 뒤에 둬

3. **여러 줄 import 를 쪼갬** — `from x import (a,\n b)` 한가운데 삽입해 문법 오류.

⇒ 일괄수정 뒤엔 **전수 컴파일 + "정의 위치 < 사용 위치" 검사**를 반드시 돌린다.

### 1.3 사용자 인터페이스

브라우저 단일 HTML(빌드 도구 없음, 더블클릭 동작) + 파이썬 표준 라이브러리 HTTP 서버.
3D 두부·전극 뷰(three.js), 표적 선택, 방법 선택, 가중치 슬라이더, 결과 패널, 한/영 전환.

2026-08-18 시각·UX 개편을 수행했다. 설계 토큰 80개를 도입해 색·간격·타이포를 한 자리로
모으고, 대비 감사에서 보조 글자색이 **2.77:1(WCAG AA 미달)** 인데 하필 단위(V/m)·복셀 수 같은
**정보를 담은 글자**에 쓰이는 것을 발견해 램프를 넓혔다(10.05 / 6.03 / 4.58, 셋 다 AA).

**모션 방침(연구 도구로서 중요)**: **숫자와 결과는 애니메이션으로 등장시키지 않는다.** 값이
올라가거나 페이드인하면 확정된 값인지 의심하게 된다. 허용은 색·테두리 전이 ≤120 ms 뿐이다.
진행 표시가 멎어 보이는 문제는 시머가 아니라 **경과 시간 + 단계 문자열**로 풀었다.

**전류 경로 시각화**: 전극에 마우스를 올리면 모든 채널의 전류 경로가 나온다. 경로는 3차
베지에로 **표적을 정확히 통과**하도록 유도했다 — 제어점을 각 전극→표적 직선 위 s = 4/3 지점에
두면 되고(기하와 무관한 상수), 전 기법·전 조합에서 표적까지 거리 0.00 mm 다.

**엔벨로프 형성 그림**: 두 반송파 → 간섭 → 포락선을 결과 패널에 상시 노출한다. 값은 서버가
표적 중심에서 실제로 계산한 E₁·E₂ 투영이며, `Tmax = 2·min(a₁,a₂)` 자가검증을 매번 통과한다.

### 1.4 Sim4Life 연동

**MCP(Model Context Protocol) 헤드리스 세션** 구축 — Sim4Life 9.6 파이썬을 외부에서 구동해
모델 조작·솔브·후처리를 자동화한다.

주요 확인 사항:
- **헤드리스 솔버 "실행 불가"는 오진이었다** — QS 솔버는 끝까지 돌아간다. 원인은 설정 무효였고
  `network` 문구는 예외 기본값이었다.
- `CreateVoxels()` 를 `WriteInputFile()` 보다 먼저 불러야 한다.
- 구동 전극 교체는 `AcquireComponent → AssignSettings → RemoveSettingsFromComponent` 순서.
  전극당 약 150초.
- **`Transform(Mat3)` 은 회전 전용**이다 — 배율을 조용히 버린다. 전극 확대에서 이걸 못 잡았으면
  "전극 크기 무관"이라는 **정반대 결론**을 낼 뻔했다(1.6절 자가검증 참조).
- 솔버 라이선스가 **1좌석**이라 병렬 솔브가 불가하다.

**몽타주 분석 캐시**: 내용주소 키(모델 지문 포함) 기반. 405초 → 0.5초. 원칙은
**"캐시가 답을 바꾸면 안 된다"**. 표적은 캐시 키에 넣지 않는다(E 필드는 표적과 무관) —
대신 뇌 복셀 E를 캐시에 넣어 표적을 바꿔도 재솔브 없이 1.4초에 지표가 다시 나온다.

## 2. 리드필드 정합·검증 — 외부 기준과의 대조

우리 리드필드가 옳은지를 **독립 경로**로 확인하는 작업이다. 이 절의 결론이 뒤의 모든 수치의
신뢰 구간을 정한다.

### 2.1 대조 기준 — tip.lite

IT'IS 의 TIP 도구(tip.lite)가 **같은 MIDA 모델**에 대해 공개한 CSV(53몽타주, 4표적)를 기준으로
삼았다. 우리 리드필드에 같은 전극·같은 전류를 넣어 M1·M2·M3 를 계산해 비교한다.
**최적화가 개입하지 않으므로 순수한 지표 차이만 남는다.**

정합에 필요한 규약 넷을 확정했다:
1. **off(비표적) = 회백질(GM, label 75)만** — GM+WM 이 아니다. 이 하나로 선택성 비(우리/tip)가
   0.77 → 0.98 로 거의 일치했다.
2. **WP = w₁·M̂1 + w₂·M̂2 − w₃·M̂3** (각 지표는 후보집합 내 최댓값으로 정규화, M3는 빼기).
3. **전류 = 최대 채널 = 1.0 정규화**.
4. M3 백분위 = p50.

**★규약 3에서 큰 오차가 숨어 있었다.** 대조 스크립트들이 CSV의 a₁·a₂ 를 그대로 곱하고 있어서
M1비가 `max(a₁,a₂)` 배만큼 작게 나왔다. 52몽타주 중앙 1.159 → **보정하면 2.261**.
**엔진은 원래 옳았고 틀린 것은 대조 스크립트였다.** 이 오차가 원본 리드필드의 2.3~2.5배
과대를 상쇄해 **문제를 통째로 가리고 있었다.**

### 2.2 절대 스케일 감사

**증상**: 시상 TI 엔벨로프가 총 2 mA에서 1.22 V/m — 문헌 상한(0.2~0.8 V/m)의 **4~6배**.

독립 증거 둘:
- **문헌 실측 대조** — Lamoš STN ×2.3 · Violante 해마 ×3~6 · TI 시상 문헌 ×5~8
- **전류 플럭스** `∮σE·dA` — T7~T8 사이 **모든** 평면에서 통과전류가 주입 1 mA를 초과.
  뇌 몫 30%를 만족하려면 ÷4.5 ~ ÷9.7.

**★원인의 절반을 팬텀 실측으로 확정했다 — 정확히 2배.**

4구 팬텀을 헤드리스로 풀어 1 V 구동 시 주입전류를 세 방법으로 쟀다:

| 방법 | 값 |
|---|---|
| `∫(El. Loss Density) dV` ← **리드필드가 쓰던 값** | 0.31595 mA |
| `∫Re(J·E*) dV` (= `∫σ|E|²dV`) | 0.63190 mA |
| **전하보존 실측 `∫Jx dA`** (평면 5곳 편차 **0.000%**) | 0.66349 mA |

격자를 조이면 비가 정확히 **2.0**으로 수렴한다(3 mm 2.1125 → 1 mm 2.0348).

**기전**: Sim4Life 의 E·J 는 최대 진폭으로 저장되는데 `El. Loss Density` 는 시간평균 규약
`σ|E|²/2` 다. `injected_current()` 의 **docstring 은 `I = ∫σ|E|²dV` 라고 옳게 적어 놓고 구현은
그 절반을 적분**하고 있었다. 2.0은 정의에서 나오므로 **기하와 무관**하다 — 실물 두부에서도
`∫σ|E|²/∫LossDensity = 2.0000` 을 확증했다.

**⇒ 기존 절대 단위 값은 전부 ÷2 해야 한다.** 남은 2~3배는 미해결이다.

**폐기한 가설들** (전부 대조로 죽음): 전도도가 원인(오히려 IT'IS σ가 SimNIBS보다 **높다** →
E는 낮아지므로 과대 원인이 될 수 없다) · 유효전도도 역산 · GM/WM 도약비 · 두개골 σ · 두피 σ ·
DB 선택 · 복셀러 순서.

### 2.3 전극 크기 — 초기 결론의 정정

초기에 "전극 크기 무관(두개골이 지배, 3 cm² vs 0.5 cm² 99.8% 동일)"이라 판정하고 재생성을
건너뛰었다. **이것이 나중에 뒤집혔다.**

실제 프로토콜·tip.lite와 같은 **3 cm²** 전극으로 84전극을 재솔브한 결과:

| 지표(우리/공개 비) | 0.5 cm² | **3 cm²** |
|---|---|---|
| M1비 | 1.139 | **1.118** |
| M2비 | 0.956 | **0.988** |
| M3비 | 1.098 | **1.053** |
| 몽타주 선정 후회 | 29.4% | **10.1%** |
| 상위 1위 일치 | 1/4 | **2/4** |

최적 몽타주 자체는 불변이다. 현재 기본 리드필드가 이것이다(`TIP_LEADFIELD_DIR` 로 되돌림 가능).

**★★이 작업에서 "잣대가 오염되면 부호가 뒤집힌다"를 실증했다.**
같은 두 리드필드인데 판정이 **정반대**로 나왔다:

| 잣대 | 0.5 cm² → 3 cm² 의 M2 |
|---|---|
| 내가 만든 "정본 기준" 솔브 | 0.857 → 0.835 (**악화**) |
| tip.lite 공개 CSV | 0.956 → 0.988 (**개선**) |

오염의 정체: 내가 만든 기준 모델은 `ConductivityAnisotropic=False` 로 이방성을 껐는데,
그것이 등방 평균을 만드는 게 아니라 **이방성 조직 3종을 딴 값으로 떨어뜨린다**(백질 5.56배·
중뇌 2.95배). 나는 오염된 잣대로 **"전극 크기 가설 기각"을 먼저 선언했다가 되돌렸다.**

⇒ **잣대를 만들었으면 그 잣대 자체를 독립 경로로 검증한 뒤에 쓴다.** 여기서는 입력파일의 σ
다중집합 비교(솔브 불필요, 몇 초)와 tip.lite 배포 `Materials.db` 직접 조회가 그 역할을 했다.
**"설정을 껐다"가 "물리를 껐다"를 뜻하지 않는다.**

## 3. 최적화 원리와 자극 방법론

### 3.1 지표 정의

**엔벨로프(포락선)**

    Tmax(x) = 2 · max_n̂ min( |n̂·E₁(x)| , |n̂·E₂(x)| )

방향 잣대를 쓸 때는 `max_n̂` 대신 지정 축 n̂ 을 쓴다(`directional_env`).

**핵심 성질 — 전류에 대한 1차 동차성.** 모든 채널 전류를 k배 하면 Tmax도 k배다. 따라서

| 지표 | 정의 | 전류 스케일 |
|---|---|---|
| **M1 (강도)** | 표적 Tmax 중앙값 (V/m) | ×k |
| **M2 (초점)** | (표적 RMS / off RMS)² | **불변** |
| **M3 (누출)** | 표적 중앙값을 넘는 off 부피 % | **불변** |
| **WP (종합)** | 0.5·M̂1 + 0.5·M̂2 − 0.5·M̂3 | — |

이 동차성 덕분에 **한 규약에서 찾은 해를 다른 규약의 예산으로 다시 채점하는 것이 근사가 아니라
정확**하다. 탐색을 다시 돌리지 않고도 공정 비교가 된다.

**용어 규약**: M1=세기/strength, M2=초점/focality, M3=누출/leakage.
**"선택성(selectivity)"은 뉴런 선택성 전용으로 예약**했다 — 필드 초점(M2)과 뉴런 선택성은
다르기 때문이며, 4부에서 그 둘이 실제로 갈라지는 것을 보인다.

### 3.2 공정성 — 이 연구가 가장 많이 배운 축

**★핵심 사건: 잣대가 방법마다 달라 승자가 뒤바뀌어 있었다.**

벤치마크 머리글은 "같은 총 주입전류(config.ITOTAL)"라 적혀 있었는데 좌시상에서 실제로는:

| 방법 | I_total | 규약 출처 |
|---|---|---|
| classic | **2.00 mA** | `config.CURRENT_NORM=max_channel` (tip.lite 정합용) |
| dual | 1.00 | 모듈 상수 `DUAL_BUDGET = ITOTAL/2` |
| distributed | 1.00 | 총전류 예산 |

**classic 이 전류를 2배 쓰며 iso M1 0.141로 1위**를 찍고 있었다. 포락선은 전류에 1차이므로
**dose 아티팩트**다 — 같은 전류로 맞추면 0.080으로 꼴찌가 된다.

규약을 읽는 지점이 **네 곳**으로 흩어져 있었고, 가장 위험한 것은
`optimize_gevd(..., Imax=2.0, ...)` **기본 인자 하드코딩**이었다 — `config.IMAX` 를 바꿔도
반영되지 않아 그 방법만 조용히 다른 규약으로 돌았다.

**해결**: 규약을 하나로 못 박지 않았다(tip.lite 정합엔 최대채널, 방법 비교엔 총전류 고정이
각각 정당하다). 대신 **어느 규약인지가 결과에 항상 따라붙게** 했다.

- `Protocol` 프리셋 **FAIR**(총전류 고정·off=gm_wm) · **TIPLITE**(최대채널·off=gm)
- `protocol.use(prot)` 컨텍스트 관리자로 블록 전체에 선언 — 인자를 꿰면 하나를 빠뜨리고
  그곳은 **조용히** 옛 규약으로 돈다.
- **자가검증 칸**: "총전류 규약이면 환산 배율은 구조상 반드시 1.0". 이 칸이 실제로 버그를
  잡았다 — 탐색만 `with` 로 감싸고 채점을 밖에서 부른 누수(classic I_raw 1.72 mA, 총전류
  규약에서 나올 수 없는 값).

⇒ **탐색과 채점은 한 블록에 묶어야 한다.**

**용량(dose) 기준의 함정**: `dose_basis="peak"`(순간 최대 전류)로 고정하고 다른 값은
`NotImplementedError` 로 막았다. **peak 은 시분할에 유리한 유일한 기준**이기 때문이다 —
전극당 시간평균 부하로 바꾸면 시분할의 이득이 사라진다. 표를 인용할 때 이 조건을 함께 적어야
한다.

### 3.3 구현한 방법 7종

| 방법 | 원리 | 자유도 |
|---|---|---|
| **classic** | 2쌍 4전극 전수탐색(2단 coarse→refine) | 전극 4 + 전류비 |
| **nsga** | 자체 NSGA-II(전수 불가한 큰 풀용) | 위와 같음, 근사 |
| **dual** | 2+2 독립 TI 시스템, 결합 = env_A + env_B | 전극 8 + 비율 2 + 주파수 4 |
| **distributed** | 두 반송파를 각각 자유 다전극 전류벡터로 | 전극 K개 전류 2벌 |
| **timemux** | K개 몽타주를 duty로 순차 스위칭 | 슬롯별 몽타주 + duty |
| **selective (β)** | 이중기전(필드+AF)·방향최악 목적 | classic 형 |
| **af / gaf** | 활성화 함수 / 케이블 필터 AF를 목적으로 | classic 형 |

**dual 의 조인트 전수화**: 초기에는 시스템 A·B를 따로 찾았는데, "2위+3위가 1위+4위를 이길 수
있다"는 지적이 맞았다. 전극이 겹치지 않는 모든 (A,B) 쌍을 결합 엔벨로프의 WP로 전역 평가하도록
바꿨다(조인트 0.890 vs greedy 0.859).

**distributed 의 Huang 백엔드 전환**: 자체 가중합(WP) 목적은 **초점을 밀면 변조가 붕괴**하는
구조적 한계가 있었다. Huang 2020 의 제약형(표적 변조 최대화 s.t. off 변조파워 ≤ Pmax)이
등강도에서 지배해, `optimize_distributed` 를 Huang 래퍼로 교체했다(M2_dir 약 1.8 → 4.44).
**교훈: 가중합보다 제약형이 강도↔초점 트레이드오프에 구조적으로 우월하다.**

### 3.4 방법 비교 — 통합 규약 결과

**FAIR 규약**(총전류 고정 1 mA, ≤2 mA/전극, off=gm_wm, M3 p50)에서 7방법 × 4표적:

전체 표는 `outputs/research/unified_bench.md` 에 있다. **모든 방법이 환산 배율 1.0에서

**표적 의존성이 지배적이다 — 보편 승자가 없다.**

| 상황 | 답 |
|---|---|
| 표면 + 특정 축 자극 | **분산(배열)** — 축 방향 선택성 압도 |
| 심부·중앙 표적 | **dual / 분산** — 등전류에서도 classic을 이김 |
| 표면·비방향성 | **classic** — 최강·최초점, 복잡한 방법 불필요 |

심부에서 dual 이 classic 의 2배 M1을 내는 것은 **dose 아티팩트가 아니라 진짜 자유도 이점**이다
(2채널로는 심부에 필드를 집중할 수 없다).

### 3.5 닫힌 방향들 — 음성 결과

**(가) 위상(복소 전류) — 종결**

두 반송파의 전극별 전류를 복소수(진폭+위상)로 풀어 타원편광까지 허용했다. 같은 warm-start에서
실수 전용 재최적화 대비 순수 위상 이득:

| 표적 | WP 이득 | 위상 활용도 |
|---|---|---|
| 해마 | +0.014 | 0.05 |
| 시상 | +0.004 | 0.03 |

**극한 테스트로 "위상이 언제 작동하는가"를 확정했다.** 표적 즉시 주변(2~12 mm 껍질)을 off로
잡고 선택성을 극단으로 밀면 위상 이득 **+0.816**(M2 2.04 → 6.02)이 처음 나타난다. 그러나
그 지점의 **M1 = 0.004 = 대조군의 약 1/150** — 표적을 사실상 자극하지 않는 퇴화해다.

⇒ **위상의 phased-array 능력은 실재하나 강도를 0으로 버린 극한에서만 발현한다.**
의미 있는 자극 강도가 있는 모든 실용 영역에서 실수 다전극 대비 <2%.
(위상-TI 선행연구가 강도 제약 없이 초점만 최적화했다면 이 퇴화 영역 이득을 보고한 것일 수 있다.)

**(나) N-반송파(>2) — 종결**

N개 반송파(각 ITOTAL/N) = N몽타주 엔벨로프 평균. 시상 등방 M1:
N1 0.632 → N2 0.877 → **N3 0.914(정점, +4%)** → N4 0.864.
그러나 **선택성 M2는 N에 단조 감소**(2.65 → 2.10).

⇒ **최적 N ≤ 2.** N>2의 강도 +4%를 선택성 손실이 상쇄한다.

**(다) 시분할의 강도 이득 — 수학적으로 불가**

시간평균 시분할은 **볼록결합**이므로 최고 단일 몽타주를 초과할 수 없다. 또한
**고정 총전류 dual TI = 조인트 최적화된 2슬롯 시분할과 비트 단위 동일**하다
(tmax 1차 동차성에서 따라온다). 즉 dual 이 이미 그 최적을 찾는다.

### 3.6 시분할 — 세 번 뒤집힌 판정

이 항목이 이 연구에서 판정이 가장 많이 바뀐 곳이라 경과를 그대로 남긴다.

| 시점 | 판정 | 무엇이 틀렸나 |
|---|---|---|
| 초기 | 강도 +42% | **불공정 대조군** — 안전 미최적화 단일과 비교 |
| 2026-07-26 | 이점 없음 | 저강도 구간만 봄 |
| 2026-07-29 | 고강도에서 초점 +18~47% | **탐색 표본 과적합**(표적 400·off 1200) |
| **2026-08-13** | **방향 축에서 ×1.18~1.76** | 공정성 4축 통제 후 |

**★최종 판정 — 공정성 4축을 통제한 재측정**

사용자 지적: "시분할은 시간에 따라 변하니 상수인 기본 TI와 같은 지표로는 공정 비교가 안 되는
것 아닌가." **절반만 맞다** — 단일 몽타주는 시간상수라 어떤 시간누적 규칙에도 불변이므로
규칙 선택은 시분할 쪽만 움직인다.

통제한 4축:
- **(A)** K=1 이면 classic 지표와 **정확히 일치하는** 범함수만 사용(`ti.tmax_timeavg`).
  `Σ w_k·tmax_k` 는 슬롯마다 다른 방향의 최대를 더하는 상한이라 **실격**이다.
- **(B)** 등 dose — 슬롯당 총 주입전류 = ITOTAL
- **(C)** 시간누적 `L^p` 다이얼 `(Σ w_k env_k^p)^{1/p}`, p = 0.5·0.75·1·2·4·∞
- **(D)** 방향 잣대 3종 — `dir`(둘 다 축) · `iso`(둘 다 방향최대) · `mixdir`(표적=축, off=최악방향)

각 (규칙, 잣대) 조합마다 **혼합을 그 목적함수로 다시 최적화**한 뒤에만 표를 만들었다.

**결과 ①**: 07-29의 "고강도에서만 +18~47%"는 **기각**. 표본을 키우고 정밀 재평가하면
이득은 백분위 의존성이 없고 크기도 ×1.02~1.19에 그친다.

**결과 ②**: 진짜 이득은 **시간 축이 아니라 방향 축**에 있다. `mixdir` 기준
**피질 C3 ×1.76 · 해마L ×1.23~1.44 · 시상L ×1.18**.

**결과 ③ (기전 확정)**: **Jensen 여유분**. `max_n̂` 은 볼록이므로

    max_n̂ Σ w_k·env_k(n̂)  ≤  Σ w_k·max_n̂ env_k(n̂)

슬롯마다 **최악 방향이 다르면** 시간평균이 최악방향 off 를 구조적으로 낮춘다.
실측 여유분은 **단일 정확히 1.000 · 혼합 1.18~1.92**이고, **p=∞ 에서 여유분이 1.000이 되는
순간 이득도 1.000이 되며 최적해가 K=1로 붕괴**한다 ⇒ 이득의 출처가 이것 하나뿐이고 다른
경로가 없다.

이는 07-28의 "엔벨로프는 비음수라 상쇄 불가"가 **크기 축** 이야기였고 **방향 축에는 이 경로가
남아 있었다**는 뜻이다 — 원 아이디어 "순차 다각도"에 정확히 대응한다.

**결과 ④ (니치 반전)**: 여유분이 **피질 1.82~1.92 vs 시상 1.18~1.28**.
심부는 어느 몽타주를 써도 필드 방향이 비슷해 다양화 여지가 작다.
**⇒ "시분할 니치는 심부"라는 주장은 기각. 니치는 표층이다.**

**결과 ⑤**: p<1(쉬는 사이 회복이 있어 간헐 자극이 연속보다 불리한 경우)이면 이득이 커진다
(해마 mixdir p1 ×1.436 → p0.5 ×1.506). **실효 p는 슬롯 길이 대 막 시상수가 정한다** —
프로토콜 설계 변수이며 NEURON 하네스에 실제 스위칭 파형을 물려야 결판난다.

**대조군 4종 전부 통과**(전극풀 20→28 · 스크리닝 250→600 · 전류규약 · 방향격자 16→48).

**미해결**: 배열(Huang)은 **동시** 자극이라 이 볼록성 여유를 못 받는다 → `mixdir` 잣대에서
배열 대 시분할 재대결이 남은 질문이다(미실행).

### 3.7 Huang 2020 재현 — 외부 이론과의 대조

Huang·Datta·Parra (J. Neural Eng. 17 036023) 를 구현해 비교했다.

논문 핵심 둘:
1. **최대 변조 = HD-TES 융합**(s₁ = s₂, 100% 변조) — **TI에 강도 이점이 없다**는 수학적 증명.
2. **초점 최적화**는 off 변조파워 제약 하 표적 변조 최대화이고, off의 `min()` 이 비볼록이라
   볼록 완화하면 다시 융합으로 돌아간다 — 초점 이득은 **대칭 붕괴**에서만 나온다.

**★①이 우리 공정 벤치 결론과 독립적으로 일치한다** — TI는 강도가 아니라 초점만 준다.
peer-reviewed 근거를 확보한 셈이다.

**★배열 크기가 핵심이라는 정정**: 초기에 "심부에서 우리 방향 2쌍이 Huang 배열보다 초점적"이라
결론했으나, 이는 `select_k=16` 으로 배열을 묶어 놓은 **아티팩트**였다. 풀을 늘리면:

| 전극 풀 | 표적 변조 | 초점(cm↓) | M2 |
|---|---|---|---|
| 16 | — | 6.07 | 무승부 |
| 40 | 0.42 | 5.74 | 4.09 |
| **70** | **0.46** | **5.68** | **4.57** |

⇒ **전극이 많을수록 심부 초점이 좋아진다(논문 취지 확증). 배열을 충분히 쓰면 방향 2쌍을
지배한다.** 이전 결론은 내 탐색공간 제한이 만든 것이었다.

## 4. 생리학적 검증

여기서 묻는 것은 **"필드 지표가 실제 뉴런 반응을 대신할 수 있는가"** 다.
답은 대체로 **"아니오"** 이고, 어디서 왜 갈리는지가 이 절의 내용이다.

### 4.1 왜 필요한가 — 필드 지표의 구조적 한계

뉴런의 실제 구동은 필드 **크기**가 아니다. 긴 유수 축삭은 **활성화 함수**
`AF = ∂(n̂·E)/∂s`(축 방향 필드의 축 기울기)로 구동되고, 말단·굴곡부는 필드 투영으로 구동된다.

**선행연구 갭**: TI 몽타주 최적화는 **전부 E-필드 엔벨로프 크기 초점**을 목적으로 쓴다.
생물물리 모델(NEURON)과 안전 예측기는 **역치·안전용**이지 최적화 목적이 아니다.
⇒ **AF를 목적함수로 몽타주를 최적화하는 각도가 미개척**이었다.

### 4.2 필드 최적 ≠ AF 최적 — 견고한 결과

리드필드 위에서 AF를 계산(KDTree 이웃 유한차분)해 두 목적을 정면 비교했다.

**좌해마 결과**: |n·E| 와 |AF| 의 상관 **0.28**(거의 독립).
필드 최적 전극(F7,F9,T8,TP10) vs AF 최적 전극(F6,Fz,P7,P9) — **겹침 0/4**.
교차 평가에서 각자 자기 목적에서만 이긴다.

**5표적 지도**(필드M2 / AF M2 / 전극 겹침):

| 표적 | 필드 M2 | AF M2(AF최적) | 겹침 |
|---|---|---|---|
| 해마 | 4.76 | 0.88 | 2/4 |
| 시상 | 5.93 | 1.48 | 1/4 |
| 편도체 | 5.53 | 2.71 | 1/4 |
| **미상핵** | 7.86 | **5.93** | 1/4 |
| 조가비핵 | 4.79 | 1.88 | 3/4 |

**⇒ 견고(5/5): 필드 최적 ≠ AF 최적.** 두 목적은 진짜 다른 최적화 문제다.

**물리적 함의**: |AF| 의 표적/off 비가 **0.31**(필드는 0.66) — 심부 표적의 활성화 함수가
주변의 1/3 수준이다. AF 최적 몽타주조차 M2 ≈ 1(선택성 거의 없음)인데 필드 M2는 ~4다.
**⇒ 긴 섬유가 활성 주체라면 TI 심부 초점은 필드 지표가 말하는 것보다 훨씬 나쁘다.**

### 4.3 NEURON 검증 — 위치 의존성 확증

MRG 유수 축삭 모델로 실제 역치를 쟀다(맥·WSL 두 환경, 역치 297/297 완전 일치로 이식 검증).

**(가) 심부·통과 섬유 → AF 우세**
`af_opt` 몽타주가 최저 역치: **v1 24/24 → v2 24/24 유지**, 독립 표적(시상L)에서도 12/12.

**(나) 피질·말단 → 필드 우세**
방사 배향 피질 표적에서 `field_opt` 최저 역치(MRG10: field 4.9 < af 6.7 < gaf 8.8).
**심부와 정반대다.** 기전: 방사축에서 AF는 세 몽타주가 거의 같은데(1.63/1.63/1.70)
field_opt만 필드가 2.5배다 — 말단은 필드 구동이므로 압승.

⇒ **Mirzakhalili 의 위치 의존(말단=필드, 축 중간=AF)을 몽타주 맥락에서 직접 확증했다.**

**(다) ★보너스 — 언제 NEURON이 필요한가**
말단 지배 표적은 **축방향 E만으로 몽타주 순위를 12/12 예측**한다(AF는 역치와 Spearman 0.02로
무관). **관통 섬유 표적만 뉴런 모델이 필요하다.**

**(라) GAF(케이블 필터 AF, Peterson·Grill MDF2) — 무용 판정**
구현해 검증했으나 직선 축삭에서 **raw AF를 못 이긴다.** 개체군 수준에서는 더 강하게,
**af 와 gaf 가 구분되지 않는다** — NEURON 역치 표적 192개 중 **154개(80%) 완전 동률**이고,
공간적으로 충분한 off 개체군에서는 **최적 몽타주가 전극·비율까지 완전 일치**한다.
성긴 off 에서 갈리던 것은 아티팩트였다.
⇒ 정확한 형태는 "못 이긴다"가 아니라 **"같다"** 이다. GAF 이점은 분지·굴곡 형태에서만
가능하며 직선 MRG에는 없다.

### 4.4 섬유 개체군 파이프라인

단일 축삭에서 **실제 궤적 개체군**으로 올렸다.

**파이프라인**: ①[S4L] `ViP.GenerateSplines` → 궤적 ②[로컬] 전극별 Vₑ = −∫E·dl → 섬유
리드필드 ③[로컬] 전수탐색 ④[로컬] 후보 내보내기 ⑤[맥] standalone NEURON 역치.

**핵심 설계 근거**: 케이블 응답이 Vₑ에 **선형**이므로 전극별 Vₑ를 궤적 위에 1회 계산해두면
임의 몽타주는 로컬 중첩으로 즉시 나온다 → **만 개 전수탐색을 유지**할 수 있다.
검증: 선형중첩 vs 직접계산 상대오차 **1.13e-15**, 몽타주당 **0.12~0.14 ms**.

**자산**: 표적 다발 194궤적(좌해마, 직선도 **0.893** — 합성 직선보다 현실적) +
off 개체군 1200섬유 = 총 1394섬유 × 70전극.

**★결과 (맥 NEURON, MRG 10 µm 관통섬유, 914섬유 완주, 3.5시간)**

| 항목 | 결과 |
|---|---|
| 표적 역치 중앙값 | field 27.35 / **af 20.45** / gaf 27.35 |
| 짝지은 `af < field` | **표적 79.2%(152/192)** vs **off 51.8%(동전)** |
| kHz 블록 발생률 | field 41.0% · af 28.7% · gaf 30.2% |

**⇒ af 우위는 표적 특이적이지 전반적 강도가 아니다.** off에서 51.8%(우연 수준)라는 것이
이를 확정한다.

**★필드 지표의 예측력 — 정밀한 결론**

| 지표 | 역치 예측 |
|---|---|
| **M1(세기)** | **거꾸로 예측한다** — M1 최대인 field_opt 의 실측 역치가 최고(=가장 안 켜짐) |
| **M2(초점)** | **정확히 예측한다** — M2 7.68→14.88→18.25 ↔ ROC AUC 0.8416→0.8736→0.9105 (3/3) |

⇒ 기존의 "필드 지표 무용"보다 정밀한 결론이다: **세기 지표는 못 쓰고 초점 지표는 쓸 수 있다.**

**★이 작업에서 겪은 함정 넷** (전부 실제로 결론을 바꿀 뻔했다):
1. **선택성을 단일 작동점으로 비교하지 말 것.** 이득 격자가 성기면(8점/decade = ±17%) 두
   몽타주가 같은 격자점에 얹혀 우열이 뒤집힌다. 반드시 **AUC + 여러 작동점**을 함께 본다.
2. **off 섬유는 개수가 아니라 공간 커버리지다.** 60시드×12줄(720)은 절점 수가 복셀 off와
   비슷해도 60곳에 뭉쳐 있어 **M2를 20~50% 과대평가**한다.
3. **궤적 자르기 길이가 숨은 자유 파라미터다.** 임의로 자르면 표적에서 정확히 10.4 mm에
   인공 활성 말단이 생기고, 말단은 축삭 중간보다 **16배 흥분성이 높다**(7.0 vs 112 V/m).
   ⇒ **관통(absorbing) 조건 결과만 유효하다.**
4. 복셀 off(GM만)와 섬유 off(GM∪WM)는 기준이 다르므로 같은 표에 놓고 해석하면 안 된다.

### 4.5 반송파와 복조 — 임상 문헌과의 접점

임상 두 갈래가 서로 다른 반송파를 쓴다: Lamoš 등 **9.00/9.13 kHz**, eBioMedicine STN 교차 RCT
**2000/2130 Hz**. 둘 다 Δf = 130 Hz 로 효과를 보고했다.
**"높은 반송파에서도 엔벨로프 복조가 사는가"** 를 MRG 하네스로 쟀다.

**복조 이득** = (진폭정합 연속반송파 역치) / (TI 비트 역치). >1 이면 맥놀이가 유리하다.

| 굵기 | 절간 | 2 kHz | 5 kHz | 9 kHz |
|---|---|---|---|---|
| 7.3 µm | 0.75 mm | 2.61 | 2.37 | **2.49** |
| 10.0 µm | 1.15 | 2.43 | **1.00** | **1.00** |
| 12.8 µm | 1.35 | 2.55 | **1.05** | **1.02** |
| 16.0 µm | 1.50 | 2.61 | **2.32** | **1.00** |

**⇒ 2 kHz는 굵기에 거의 무관하게 2.4~2.6배 이득. 9 kHz는 7.3 µm에서만 유지되고 10 µm
이상에서는 완전 소멸(≈1.0).**

**독립적으로 확인된 법칙 둘**:
1. **발화 개시 역치 ∝ 1/d²** — 외삽 오차 2 kHz +3/+7/+3%, 9 kHz −2/+4/−6%.
   세포외 자극의 고전 결과를 모형이 재현한다 = **모형 검증**.
2. **맥놀이 이점의 정체는 kHz 블록 회피** — 원시값에서 직접 보인다. 7.3 µm @9 kHz는 비트가
   단조(블록 없음)인데 대조군은 블록 밴드에 걸린다. 10~16 µm @9 kHz는 비트도 블록에 걸려
   지속역치가 대조군과 **같은 천장**에 묶인다.

**★반증된 가설 — 기록으로 남긴다**
9 kHz까지만 봤을 때 "전이가 무차원수 Λ = 절간 × √f 로 접힌다"는 정리를 세웠고 8점이 깨끗하게
접혔다. **5 kHz 예측 검정에서 죽었다** — 16.0 µm는 Λ=106으로 전이 한참 위라 ~1.0을 예측했는데
**2.32**가 나왔다. Λ는 두 변수 모두에 단조라 관측된 비단조 패턴을 **원리적으로 만들 수 없다.**

⇒ **8점에 1모수를 사후로 맞춘 것은 근거가 아니다. 예측 검정 전에 "물리적 경향성"이라 부르지
말 것.**

**★방법론 — 격자 해상도가 시뮬 가능한 반송파 상한을 정한다**
Vₑ를 가우시안 σ로 저역통과해 역치를 다시 재는 검사를 했다. 8.7 µm는 2 kHz에서 통과(0%)하는데
9 kHz에서 **실격(58%)** 한다. 반송파가 높을수록 교류 공간상수가 짧아져 섬유가 더 미세한 구조를
보기 때문이다.

⇒ **리드필드 격자(0.4~0.9 mm)가 9 kHz에서 감당하는 것은 절간 ≥1.15 mm(10 µm 이상)뿐이다.**
그런데 **임상 대조(Lamoš)가 걸린 쪽이 거기다** — 9 kHz 열은 2 kHz 열보다 체계적으로 덜 믿을
만하다.

**임상 함의(검정 가능한 예측)**: Lamoš 9 kHz에서 STN 관련 섬유가 굵으면(유수 투사섬유 ~10 µm)
맥놀이는 기여하지 않았고 관측 효과는 **반송파 자체**가 낸 것이다. 가늘면(~7 µm) 복조가 살아
있다. 2 kHz RCT는 굵기 무관하게 이점이 있다.

⚠ **한계**: 케이스 하나(시상L·field_opt·관통섬유)이고 Lamoš는 STN이라 **외삽**이다.

### 4.6 선택성 — TI의 근본 한계

**질문**: TI가 심부에서 선택적인가? 즉 표적 뉴런이 off 뉴런보다 먼저 켜지는가?

off 축삭은 (ㄱ)**모든 방향**으로 배향돼 있고 (ㄴ)**두 기전**(말단=필드 크기, 섬유=AF)으로
켜진다. 기존 지표는 표적 축 한 방향 엔벨로프만 봐서 이 누출을 놓친다.
⇒ off를 **필드 등방 Tmax**(최악 방향 말단)와 **AF 여러 방향 최악**(관통 섬유 어느 배향이든)
둘 다에서 억제하는 (β)선택성 목적함수를 만들어 재점수했다.

**★결과 (정직)**: **최악 기전은 항상 AF이고, M2_af 가 전부 <1 이다**(off AF RMS ≥ 표적!).
M3_af 는 82~96%.

| 표적·몽타주 | 최악 M2 | 최악 M3 |
|---|---|---|
| 해마 field_opt | 0.18 | 95.5% |
| 해마 af_opt | 0.24 | 89.7% |
| 해마 sel | 0.27 | 89.1% |
| 시상 field_opt | 0.63 | 82% |

베타 옵티마이저가 최악을 개선하긴 하나 **M2_af < 1 영역을 못 벗어난다.** 필드-초점이면
AF-누출, 역도 성립 ⇒ **두 기전 모두 초점적인 몽타주가 없다.**

**⇒ 몽타주로는 TI 심부 선택성을 만들 수 없다.** 발표 가치가 있는 음성 결과이며,
심부 초점 과대평가를 교정한다.

NEURON 피질 결과에서도 독립적으로 같은 결론이 나왔다(11/12에서 off가 먼저 켜짐).

**⚠ 단, 개체군 실험에서는 재현되지 않았다.** 모순이 아니라 **off 정의의 스케일 차이**다 —
선택성 실험의 off는 표적 바로 옆 3궤적, 개체군 실험의 off는 뇌 전역 1200섬유였다.
**off를 어디로 잡느냐가 결론을 정한다.**

**Caveat**: "방향 최악 = 모든 off 위치에 최악 배향 섬유 가정"은 **보수적 상한**이다. 실제 off
섬유 배향은 백질 tract를 따라 특정돼 있으므로 진실은 단일방향(낙관)과 방향최악(비관) 사이에
있다. 현실적 답에는 **tractography 축 배향**이 필요하다.

### 4.7 진폭 현실성 — 엄밀 상한

**어떤 2쌍 몽타주로도 못 넘는 per-voxel 상한**을 닫힌 형태로 구했다(탐색공간·풀·옵티마이저 무관):

    Tmax(x) ≤ 2·min(i₁,i₂)·max_pair|d_AB(x)| ≤ I_total·max_pair|d_AB(x)|

9표적 × 2·4 mA에서, 실효 막 구동 = Tmax × 2.5(2 kHz 복조) × 스케일 밴드 0.83~0.91:

| 문턱 | 판정 |
|---|---|
| tACS 인입 **0.3 V/m** | **9/9 표적 전부** 통과 (2 mA에서 0.67~1.35 V/m) |
| 직접 스파이크 7.0 V/m (우리 MRG) | 전부 미달 — 필요 총전류 9.4~27 mA |
| tTIS 네트워크 20 V/m (문헌) | 전부 미달 — 필요 총전류 27~76 mA |

**⇒ 살아있는 기전은 미역치 인입(subthreshold entrainment) 하나뿐이다.** 나머지 둘은
**엄밀 상한조차** 못 넘으므로 몽타주 최적화로 해결될 문제가 아니다.

**★심부 강도 최적화는 이미 포화**: 상한/실제최적 비가 심부에서 **1.2~1.6배**뿐이다
(해마 0.529/0.323 · 시상 0.370/0.320 · STN 0.387/0.323). 피질만 2.5배 여유가 있다.
**⇒ 심부에서 M1을 더 짜낼 여지가 거의 없다.**

**★정면 충돌**: 문헌 tTIS는 tACS 대비 **100배 손해**(20 V/m 필요)라는데 우리 NEURON은 2 kHz
복조가 **2.5배 이득**이라 한다 — **부호가 반대다.** 이 충돌은 미해소다.

### 4.8 신경집단 모형 / 전뇌 시뮬레이터 — 전면 음성

미역치 인입은 **집단 현상**이라 단일 축삭 모델에 없다. The Virtual Brain(TVB)으로 그 층을
시험했다. **본 프로그램은 한 줄도 고치지 않았다**(사이드 프로젝트로만 진행).

**(가) 국소 신경집단(Jansen-Rit)** — 우리 구현이 TVB 구현과 상대차 0.00e+00.
Arnold tongue 재현 성공. 유도된 반응함수 g는 **전이점 아래는 문턱형(기울기 1.58~1.73),
위는 포화형(0.31~0.67)** 이다.

**(나) kHz 복조는 신경집단 모형에서 일어나지 않는다** — 인입 문턱의 500배 진폭에서도
무자극과 구분되지 않았다(TI−기저 ≈ 0). 같은 조건 tACS는 |Z| 50배.
⇒ **복조는 집단 비선형이 아니라 단일 뉴런 막에서 일어난다 = 모듈 분리(리드필드 → NEURON
복조계수 → 엔벨로프를 신경집단에)가 정당화된다.**

**(다) 빠른 대리모형은 원리적으로 불가**
전달행렬 H를 한 번 재두면 몽타주별 관여를 행렬곱으로 얻을 수 있으나, 그것은 **중첩이 성립할
때만** 맞다. 공명 안/밖 대조로 쟀다:

| 구동 | amp 0.002 | 0.01 | 0.05 | 응답 크기 |
|---|---|---|---|---|
| 25 Hz (공명 밖) | 15.5% | 41.4% | 35.2% | 0.027~0.345 |
| 10.4 Hz (공명) | **87.9%** | 86.4% | 106.3% | **8.7~19.1** |

공명은 진폭 25배 범위에서 오차가 86~106% 붙박이고 응답이 100~300배 크다 =
**위상 포획(phase locking)** 의 서명이다. 포획은 문턱 현상이라 진폭을 줄여도 사라지지 않는다.
**⇒ 우리가 노리는 것이 정확히 그 포획이므로 선형 대리모형은 노리는 현상을 정의상 표현 못 한다.**

**(라) 환산계수를 물리로 확정** — **분극 길이(polarization length)**
전기장을 신경집단 모형에 넣는 표준은 결합상수와 전기장의 내적을 **막전위에 직접** 더하는
것이다(우리는 입력 쪽에 넣고 있었다 → 교정). 문헌의 볼-스틱 뉴런을 그대로 만들어 재니
**우리 0.507 · 논문 0.5 · 손계산 0.533** 세 방향이 일치했다.

| 세포 | 분극 길이 |
|---|---|
| 우리 MRG 축삭 10 µm | 4.25 mm (이 용도엔 부적합) |
| **볼-스틱 피질세포** | **0.5 mm** ← 신경집단 문헌 값 |
| 피질 추체세포 실측 | 0.1~0.2 mm |

**★★★최종 판정 — 전기생리 도입이 더 나은 배치를 주지 못했다**

네 갈래를 모두 시도했고 전부 개선이 확인되지 않았다:

| 시도 | 결과 |
|---|---|
| 뇌 모형을 최적화 루프에 직접 | **원리적 불가**(공명 위상포획) |
| 연결 지도를 지표에 | 실익 0.05, p=0.015 아슬 |
| 목적함수 가중치 조정 | 해마 부트스트랩 0.19~0.52 → **현재 0.5가 구간 안** |
| 점별 반응함수 g(E) | 배치는 바뀌나 **더 낫지 않음**(측정 깨끗한 피질에서 자극당 −3.4%) |

**왜 실패했는지(형태의 문제)**: 점별 반응함수는 복셀을 하나씩 따로 본다. 그런데 이 작업이
확인한 핵심은 **연결을 통해 다른 곳의 활동이 표적에 영향을 준다**는 것이다. 복셀을 따로 보는
형태로는 그 경로를 담을 수 없다. **방향은 맞아도 "점별 지표"라는 형태가 생리와 안 맞는다.**

**★★★★★그리고 마지막에 잣대 자체가 무너졌다 (2026-08-18)**

"전기장으로 고른 배치가 뇌 모형 기준 몇 위인가"에 해마 2위/26 · 시상 10위/25로 답했다.
**둘 다 근거 없다.** 무자극 바닥값을 재고 나서 드러났다.

**결함**: 씨앗별 |Z|를 **먼저 취한 뒤 평균**해서 자극과 무관한 자발 진동이 상쇄되지 않았다.
게다가 자극 주파수를 네트워크 고유 리듬에 맞춰 놨으니 하필 그 주파수에 자발 진동이 가장
세게 깔린다.

    무자극 바닥 |Z0| = 1.197,  후보들 |Z| = 1.166~1.572  →  **바닥이 76~103%**

**★★진짜 교훈 — 신뢰도 관문이 바닥값 때문에 부풀려져 있었다**

| 배치 | 앞서 쓰던 반벌차 | 바닥 없는 잣대로 다시 재니 |
|---|---|---|
| 전기장 M1 1위 | 3.0% | **91.0%** |
| 다양성 22 | 7.5% | **119.8%** |

**"측정이 안정해 보인 이유는 신호가 잘 측정돼서가 아니라 측정값의 80%가 자극과 무관한 안정된
바닥이었기 때문이다."** 이 관문을 작업 전체에서 신뢰도 근거로 썼으므로 **이 관문에 기댄
결론은 전부 재검 대상**이다.

**짝지은 빼기도 실패했다(예상 밖)** — 씨앗을 맞춰 무자극을 복소수로 빼면 잡음이 상쇄될 줄
알았으나 **1.18배로 오히려 커졌다.** 원인은 **자극이 궤적을 갈라놓아 두 판의 잡음이 더 이상
겹치지 않는 것**이다(비선형계의 궤적 발산). **같은 난수 씨앗 ≠ 같은 잡음 실현.**

**측정 한계 확정**: 신호/잡음 1.0~1.5, 최고−전기장 격차 0.047 ± 0.368 = **0.13 시그마**.
2시그마로 가르려면 **씨앗 약 6,000개 = 466시간** ⇒ **이 질문은 현 예산에서 답할 수 없다.**

**물리적 의미(측정 실패가 아니다)**: 실제 TI 세기에서 자극이 만든 반응(~0.3)이 같은 주파수의
자발 요동(~1.1)보다 작다. **자극은 진행 중인 활동 위의 작은 흔들림**이고, 그래서 배치를
가르기가 원리적으로 어렵다.

**★★★★★★그리고 마지막 남은 결론까지 기각됐다 (2026-08-18 밤)**

"연결이 자극 반응을 재배치한다"는 결론에 **자극을 0으로 두고 똑같이 재는 대조군**을 처음
돌렸다:

| | 자극 있음 | **자극 없음** |
|---|---|---|
| k=0 vs k=30 상위10 겹침 | 0.5/10 | **1.0/10** |
| k=0 vs k=30 순위상관 | −0.102 | **−0.060** |

**자극을 꺼도 패턴이 똑같이(오히려 조금 더) 바뀐다 ⇒ 기각.**

통제되지 않았던 것 셋: ①결합이 자극 반응을 재배치(주장) ②결합이 **자발 활동** 패턴을 바꿈
③측정 주파수가 k=0에서 6.2 Hz, k=30에서 10.4 Hz로 **다름**(각자 공명에서 구동하므로).
측정값의 80%가 자발 진동이므로 ②③만으로 결과가 나온다. **실제로 그랬다.**

**남는 참인 진술**: "결합을 켜면 그 주파수에서 활동하는 영역이 바뀐다" — 자극과 무관하다.

**★교훈: 재현성 관문은 같은 조건 안의 씨앗 차이만 막는다. 조건 사이에 끼어든 교란은 원리적으로
못 잡는다. 관문 통과 ≠ 교란 없음.** 다섯 가지(결합세기·표적·정합섭동·분극길이·자극세기)를
흔들어 살아남았지만 **흔든 것이 전부 같은 교란을 공유**하고 있었다.

**TVB 작업 최종 대차대조표**

| 결론 | 상태 |
|---|---|
| 전기생리를 목적함수에 넣으면 낫다 | **확인 안 됨**(네 갈래 전부) |
| 몽타주 순위 비교(해마 2위·시상 10위) | **철회**(바닥값 76~103%) |
| 연결이 **자극** 반응을 재배치한다 | **기각**(자극 없이도 동일) |
| 신경집단 모형은 kHz 복조 못 함 | **유지**(직접 측정) |
| 빠른 대리모형 원리적 불가 | **유지**(공명 위상포획) |
| 실제 TI 세기에서 자극(~0.3) < 자발 요동(~1.1) | **유지** |

**⇒ 뇌 모형에서 새로 얻은 긍정적 결론은 없다. 남은 것은 전부 "무엇을 할 수 없는가"다.**

나눠야 21 mm 쥐 뇌가 전극에 안 파묻힌다.

| 3 | 드라이브별로 다른 전극 풀 | "field_opt가 자기 기준에서 진다"는 **가짜 결론** |
| 4 | 청크 안에서 정규화 | 같은 해가 **2474위↔11188위** 요동, 실행마다 답이 바뀜 |
| 5 | 표적 필드 상위 24전극 | **4.25배** 차이. 승자 전극이 상위 24 밖(51위) |
| 6 | (같은 사건) 실행 시각 | off 정의 변경 전후로 답이 정반대 |
| 7 | 단일 최적 몽타주 개념 | 상위 3개 WP 폭 0.08% — **파레토 프론트가 평평해 "최적 하나"가 정의되지 않음** |
| 8 | **잣대 자체** | 같은 몽타주가 잣대에 따라 ×0.585~2.16 |
| 9 | 단일 작동점 | 바닥 p80 한 칸만 보고 "안 바뀐다" → p40에서 ×3.71, 문턱 0.6에서 ×7.69 |
| 10 | **잣대가 오염** | 전극 크기 효과의 **부호가 뒤집힘** |
| 11 | 신뢰도 관문이 바닥값에 잠김 | 반벌차 3.0% → 바닥 걷어내니 **91.0%** |
| 12 | 흔든 축이 전부 같은 교란 공유 | 다섯 축 통과했으나 최종 기각 |

### 규약으로 승격된 것

1. **어떤 이득 주장도 (ㄱ)전체·다양 전극 풀 (ㄴ)같은 목적함수 (ㄷ)같은 총 주입전류로 최적화된
   대조군과 비교한다.**
2. **(규칙, 잣대) 조합마다 옵티마이저를 다시 돌린 뒤에만 표를 만든다.** 교차 칸은 실어도
   "해석 금지"라 적는다.
3. **"구조상 반드시 이 값이어야 한다"는 칸을 하나 심어 매 실행 확인한다.**
   이 칸이 실제로 두 번 정반대 결론을 막았다.
4. **잣대를 만들었으면 그 잣대 자체를 독립 경로로 검증한 뒤에 쓴다.**
   "설정을 껐다"가 "물리를 껐다"를 뜻하지 않는다 — 끈 뒤 **실제로 들어간 수치**를 확인한다.
5. **결론을 말하기 전에 제약 세기를 최소 3점(느슨·중간·빡빡) 돌린다.**
6. **무자극(sham) 대조를 반드시 둔다.** 재현성 관문은 같은 조건 안의 잡음만 막는다.
   물어야 할 것은 "축이 독립인가"가 아니라 **"내 주장의 원인 자체를 끌 수 있는가"** 다.
7. **비율 지표는 분모를 확인한다.** 측정값의 대부분이 바닥이면 안정해 **보인다**.
8. **비선형계에서 같은 씨앗 ≠ 같은 잡음.** 짝지은 빼기가 잡음을 1.18배 키울 수 있다.
9. **부트스트랩 구간 폭이 값의 절반을 넘으면 권고로 만들지 말 것.**
10. **예측 검정 전에 "물리적 경향성"이라 부르지 말 것.**

## 7. 현 상태와 남은 것

### 7.1 확립된 것

- **플랫폼**: 리드필드 → 7개 최적화 방법 → 지표 → 프로토콜 → Sim4Life 정밀 검증까지 완결.
  단일 규약(`Protocol`)으로 모든 방법이 같은 잣대에서 채점된다.
- **외부 정합**: tip.lite 공개값 대비 M1비 1.118 · M2비 0.988 · M3비 1.053(3 cm² 전극).
  **초점·누출 결론은 스케일 격차의 영향을 받지 않는다.**
- **방법론적 결론**: 표적 깊이와 축 요구에 따라 승자가 바뀐다(보편 승자 없음).
  위상·N>2 반송파·시분할 강도 이득은 닫혔다. 시분할 초점 이득은 방향 축에서 실재하며
  기전(Jensen 여유분)이 확정됐고 니치는 표층이다.
- **생리적 결론**: 필드 최적 ≠ AF 최적(5/5 표적 견고). 활성 부위에 따라 최적 몽타주가
  뒤집힌다(피질·말단 = 필드, 심부·통과섬유 = AF). GAF는 직선 축삭에서 AF와 구분되지 않는다.
  **M1은 역치를 거꾸로 예측하고 M2는 선택성을 정확히 예측한다.**
- **한계 확정**: TI는 심부 선택성을 몽타주로 만들 수 없다. 살아있는 기전은 미역치 인입 하나뿐.
  심부 강도는 이미 상한의 1.2~1.6배 안(포화).

### 7.2 미해결

| 항목 | 상태 |
|---|---|
| 절대 스케일 남은 2~3배 | `inj_current` 2배는 확정·수정, 나머지 미확정 |
| M2 초점 격차(부위별 0.85~1.18) | 이방성 용의, MIDA DTI 배포 없어 경로 막힘 |
| tTIS 100배 충돌 | 문헌 20 V/m vs 우리 복조 2.5배 이득 — **부호가 반대**, 미해소 |
| 배열 vs 시분할 (mixdir 잣대) | 미실행 |
| 반송파 전이 경계 | 굵기 3점·반송파 3점으로는 부족 — 11.5·14.0 µm와 3·7 kHz 필요 |
| off 섬유 배향 | tractography 필요(현재는 방향최악 = 보수적 상한) |
| 시상 | 현 목적함수의 예측력 0.07~0.14 — **타당하다는 근거가 없다** |
| 표층 표적 외부 검증 | 공개 대조값 없음 |

### 7.3 보고서 작성 시 주의할 점

1. **철회된 수치를 인용하지 말 것.** 특히 ①시분할 "고강도 +18~47%" ②TVB 몽타주 순위
   (해마 2위·시상 10위) ③"연결이 자극 반응을 재배치한다" ④정본 기준 리드필드 수치.
2. **절대 강도(V/m)를 인용할 때는 스케일 감사를 함께 적을 것** — 현재 값은 문헌 대비 2~3배
   과대일 수 있다. **비(ratio) 지표는 안전하다.**
3. **시분할 표를 인용할 때 `dose_basis=peak` 조건을 함께 적을 것** — 전극당 시간평균 부하로
   바꾸면 이득이 사라진다.
4. **9 kHz 결과는 2 kHz 결과보다 신뢰도가 낮다**(격자 한계). Lamoš 대조가 걸린 쪽이 거기다.
5. **NEURON 결과는 관통(absorbing) 조건만 유효하다** — 말단 조건은 궤적 자르기 길이가 결정한다.
6. **"단일 최적 몽타주"라는 표현을 피할 것** — 파레토 프론트가 평평해 상위 군집을 함께 봐야
   하고, 승자는 off 정의 같은 모델링 선택에 통째로 뒤집힌다.
